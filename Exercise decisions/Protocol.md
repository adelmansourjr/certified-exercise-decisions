# Does better option pricing lead to better exercise decisions?

Wei and Zheng's BPS-cGAN work uses targeted synthetic augmentation near the early-exercise boundary for American put pricing. A price is only one output of that problem. A downstream decision is whether to exercise now or continue. Test whether changing the supervision target improves that action, given the same simulation calls, data splits and small model capacity.

Use a 96-step Cox–Ross–Rubinstein American-put tree with strike normalised to 1 as the simulated reference. Each call returns the exact tree price and continuation value for that discretisation. One polynomial ridge model predicts value above exercise payoff, meaning the nonnegative part of continuation value minus the immediate payoff. The other predicts the signed continuation advantage directly. Both use the same features, training examples and solver calls. Calibrate their action thresholds independently on a common validation set with the same fixed grid, using realised decision regret. Compare both with a 16-step tree, which provides a strong cheap numerical baseline. The target estimated by each method is the only controlled model-training change.

Use sixteen independent runs. Each draws 900 training and 500 validation contracts, and two fresh 1,300-case test panels. Train and validate on portfolio-free synthetic contracts with spot-to-strike between 0.65 and 1.30, volatility between 0.10 and 0.48, rates between 0.01 and 0.12, and maturity between 0.04 and 1.25 years. One panel uses the training parameter distribution. The other reserves a higher volatility range of 0.49 to 0.68. Sample all quantities independently. For each test contract, the exact one-step regret is the value difference from forcing the selected action now and taking optimal reference decisions thereafter. Measure regret, pricing RMSE, wrong actions and regret near the boundary (advantage magnitude at most 0.003 on in-the-money cases). Force continuation for options with zero exercise payoff. Aggregate across runs and bootstrap paired run differences 5,000 times.

The initial criterion is a positive lower endpoint on paired mean regret reduction across both panels versus the calibrated price-target model. Report the comparison with the coarse solver and the absolute scales. Strong performance of the coarse solver would establish the need for a harder benchmark. This is a numerical experiment using a standard model. It measures one first-step decision and gives no conclusions about empirical markets, trading, calibrated risk-neutral parameters or exotic high-dimensional contracts. The reference and the coarse solver share the same modelling family.
